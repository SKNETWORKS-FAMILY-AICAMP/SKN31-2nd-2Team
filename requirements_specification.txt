                       요구사항 명세서 (Requirement Specification)

- 참여 팀원: 김가율, 이영창, 이용혁, 정형섭, 박연아

--------------------------------------------------------------------------------
1. 프로젝트 개요 (Project Overview)
--------------------------------------------------------------------------------
 본 프로젝트는 인공지능(AI) 모델과 웹/앱 서비스를 결합하여 사용자에게 가치를 제공하는 
 지능형 서비스 구현을 목표로 합니다. 데이터 수집, 모델 학습, 백엔드 API 구축 및 
 프론트엔드 UI 연동을 포함한 전체적인 End-to-End 파이프라인을 구축합니다.

--------------------------------------------------------------------------------
2. 시스템 요구사항 (System Requirements)
--------------------------------------------------------------------------------
2.1 하드웨어 및 개발 환경 요구사항
  - 개발 언어: Python 3, JavaScript
  - 프레임워크: 백엔드 (FastAPI / Flask / Django), 프론트엔드 (React / Vue.js / Streamlit)
  - AI 라이브러리: PyTorch / TensorFlow / Scikit-learn

--------------------------------------------------------------------------------
3. 기능 요구사항 (Functional Requirements)
--------------------------------------------------------------------------------
[요구사항 ID: REQ-F-001] 데이터 수집 및 전처리
  - 설명: 모델 학습 및 서비스에 필요한 데이터를 크롤링하거나 오픈 데이터를 활용하여 수집한다.
  - 세부 내용:
    - 정형/비정형 데이터의 정제 및 결측치 처리
    - AI 모델 학습에 적합한 형태로 데이터 피처 엔지니어링

[요구사항 ID: REQ-F-002] AI 모델 개발 및 학습
  - 설명: 요구사항 정의에 부합하는 핵심 AI 예측/분류/생성 모델을 구축한다.
  - 세부 내용:
    - 데이터셋 분할 (Train/Valid/Test) 및 교차 검증
    - 모델 평가지표(Accuracy, F1-score, RMSE 등) 기준 충족 및 최적화

[요구사항 ID: REQ-F-003] 프론트엔드 UI/UX 구현
  - 설명: 사용자가 AI 서비스를 편리하게 이용할 수 있는 웹/앱 인터페이스를 제공한다.
  - 세부 내용:
    - 사용자 입력 폼 구성
    - 백엔드 API와 비동기 통신을 통한 실시간 시각화 및 결과 화면 출력

--------------------------------------------------------------------------------
4. 비기능 요구사항 (Non-Functional Requirements)
--------------------------------------------------------------------------------
[요구사항 ID: REQ-N-001] 성능 및 속도
  - 사용자의 요청 후 AI 모델 추론 완료 및 화면 출력까지의 지연 시간(Latency)을 최소화한다.

[요구사항 ID: REQ-N-002] 코드 관리 및 협업
  - Git/GitHub을 활용하여 협업한다.

[요구사항 ID: REQ-N-003] 배포(향후 서비스 예정)
  - Streamlit 프레임워크를 활용한 웹 서비스 배포 및 호스팅한다.
